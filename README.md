# PixiDraw

A pixel art software which converts drawn pixels on a page to digital assets.

**Try it:** https://aryn-pathak.github.io/PixiDraw/

Drawing pixel art with a mouse or trackpad is hard, and most people don't have a drawing tablet. PixiDraw lets you draw on a printed graph paper sheet instead. Upload a photo of the sheet and PixiDraw rebuilds the drawing pixel by pixel, ready to edit, animate and export as a PNG or sprite sheet.

## How to use it

1. Download and print the template sheet (button on the website, or [`sheet/pixidraw-sheet.pdf`](sheet/pixidraw-sheet.pdf)).
2. At the bottom left, colour one of the outlined boxes black. Its size sets the size of your pixels (1 = 4 mm … 4 = 16 mm).
3. Start your drawing from the top-left box of the grid, colouring each pixel as desired.
4. Take a clear photo of the page with all 4 corner markers visible, preferably straight on.
5. Upload it to PixiDraw.
6. Edit if you like: change colours from the palette, erase, or draw with the brush.
7. Export as a PNG, or save as frames to build an animation and export it as a sprite sheet.

## How to use
1. Download and print the template sheet.
2. At the bottom left, colour a box black the size of the desired pixels.
3. Start the drawing from the top left box on the graph paper, colouring each pixel as desired.
4. Take a clear picture of the page with all 4 markers visible, preferably straight.
5. Upload to PixiDraw.
6. If desired, change the colours of the pixels from the palette, or erase/draw parts.
7. Export as PNG, or save as frame to create an animation that can be exported as a sprite sheet.

## Features

- Perspective correction from the four corner markers, so photos taken at an angle work
- Colour correction from the printed black / white / grey key, so lighting doesn't skew colours
- Ignores colour spill between boxes, and handles minor uneveness in colour due to ink or pencil faults and human error
- Edit all pixels of a colour at once using palettes, to fine tune colours not available in media
- Brush, eraser, undo, rotate and flip
- Animation frames with onion skinning and a live preview
- Exports a transparent PNG or a one-row sprite sheet
