How to use PixiDraw

  1. Download and print the template sheet.
  2. At the bottom left, colour a box black the size of the desired pixels.
  3. Start the drawing from the top left box on the graph paper, colouring each pixel as desired.
  4. Take a clear picture of the page with all 4 markers visible, preferably straight.
  5. Upload to PixiDraw.
  6. If desired, change the colours of the pixels from the palette, or erase/draw parts.
  7. Export as PNG, or save as frame to create an animation that can be exported as a sprite sheet.

Note: you can also draw multiple frames or characters on the same page, and later erase the extra ones in PixiDraw.
